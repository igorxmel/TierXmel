# Личный рейтинг игр

Статический сайт с личными оценками игр. Без сборки, без npm, без бэкенда — чистые HTML + ES-модули + JSON.

## Запуск локально

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000/`. По `file://` не работает: страницы читают JSON через `fetch`.

## Публикация на GitHub Pages

1. Создать репозиторий и запушить содержимое папки в ветку `main`.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Файл `.nojekyll` уже лежит в корне — без него Pages игнорирует часть файлов.

## Как устроены оценки

Две независимые оси:

- **Качество, 0–900** — взвешенная сумма критериев. Бюджет каждого блока задаёт профиль жанра, сумма бюджетов всегда 900, поэтому игры разных жанров сопоставимы.
- **Кайф, 0–100** — один слайдер, холистическое «насколько зашло».

Тир выводится из балла по порогам в процентах, руками не ставится. Тирлист строится по любой из осей — переключатель на главной.

Игру можно оценить двумя способами и только двумя:

| Путь | Что заполняется | Результат |
|---|---|---|
| Подробная оценка | кайф + все критерии применимых блоков | качество 0–900, тир на обеих осях |
| Быстрая оценка | кайф + вердикт одной строкой | тир только по кайфу, молния на плитке, полка «Ждут разбора» |

Промежуточного варианта нет намеренно: агрегатная оценка блока одним слайдером систематически завышается, и быстро заполненные игры уезжали бы выше разобранных подробно.

## Файлы данных

- `data/meta.json` — тиры и пороги, блоки и критерии, профили жанров с бюджетами, бейджи, ярлыки, статусы. **Вся система оценивания живёт здесь**, в коде чисел нет.
- `data/games.json` — массив игр. `quality`, `tier` и покрытие не хранятся: считаются при загрузке в `js/score.js`.
- `data/reviews/<slug>.md` — длинные рецензии, подгружаются при открытии карточки.
- `covers/<slug>.webp` — обложки 320×320, кладёт админка.

Правка `meta.json` пересчитывает всё разом. Добавить критерий безопасно — у старых игр он `null` и нормализация идёт по заполненным. А вот правка бюджетов профиля двигает баллы всех игр этого профиля, так что лучше сразу смотреть на гистограмму в разделе «Статистика».

## Админка

`admin/` лежит в репозитории открыто, но без ключей ничего не делает. Нужны два:

- **RAWG API key** — [rawg.io/apidocs](https://rawg.io/apidocs), бесплатно, 20 000 запросов в месяц. Нужен для поиска игр, метаданных и обложек.
- **GitHub fine-grained PAT** — права строго `Contents: write` на этот один репозиторий. Нужен, чтобы коммитить изменения прямо из браузера.

Оба хранятся в `localStorage` этого браузера и в репозиторий не попадают. Публичные страницы сайта не содержат ни ключей, ни обращений к внешним API. Токен в `localStorage` доступен любому, кто получит доступ к браузеру — поэтому права минимальны, и его в любой момент можно отозвать на GitHub.

Сохранение делает **один коммит** на все файлы сразу (данные + обложка + рецензия) через Git Data API. Кнопка «Скачать games.json» работает вообще без токена, если захочется закоммитить руками.

## Оформление

Направление — тёмное редакционное. Одно правило держит всю систему: **цвет принадлежит только тирам**, интерфейс монохромный (графит и бумага). Поэтому девять рядов читаются как шкала, а не как гирлянда, и ничто с ними не конкурирует.

Шкала тиров — не радуга, а **одноцветная золотая лестница**, гаснущая в графит: ранг кодируется яркостью, а какой это ряд — говорит крупная буква. Ступени посчитаны в OKLCH и проверены валидатором палитр: монотонная светлота, зазор ΔL ≥ 0.06 между соседями, разброс тона 1°, тёмный конец отрывается от фона. Менять цвета в `data/meta.json` можно, но ступени лучше пересчитывать, а не подбирать на глаз.

Шрифты — Unbounded (заголовки, баллы, буквы тиров) и Golos Text (текст), оба с полной кириллицей, подключены с Google Fonts. Иконки — инлайновый SVG, а не эмодзи: эмодзи рисуются системным шрифтом и выглядят по-разному на каждой платформе.

## Структура кода

```
js/score.js         вся математика и валидация — единственный источник правды
js/data.js          загрузка, нормализация, фильтр черновиков
js/filters.js       фасетные фильтры и поиск, состояние в URL
js/icons.js         SVG-иконки
js/markdown.js      разметка рецензий
js/render-*.js      отрисовка: тирлист, карточка, статистика, доска почёта
js/site.js          адреса страниц и общая шапка
js/pages/*.js       точки входа страниц
js/rawg.js          поиск игр и обложка → webp через canvas
js/github.js        коммит через Git Data API
js/admin.js         форма админки
```

## Адреса

Каждая страница лежит в своей папке, поэтому адреса без `.html`: `/stats/`, `/awards/`, `/admin/`, `/game/<slug>/`. Страницу игры админка создаёт сама при сохранении. Ссылки строятся в `js/site.js` от расположения файла, так что одинаково работают локально и на GitHub Pages, где сайт лежит в `/TierXmel/`.
